## 安装

1. 把 jar 丢进 `.minecraft/mods/`（服务端则丢进服务端的 `mods/`）
2. 方块 mod 记得同时装 [Fabric API](https://modrinth.com/mod/fabric-api)
3. 启动游戏

## 用法

**更完整的原版方块**

- 创造模式「建筑方块」页里，每个变体紧跟在它的基础方块后面（不是堆在页尾）
- 合成：切石机切基础方块 1 个 → 楼梯/墙 1 个、台阶/竖台阶 2 个；工作台也有配方（楼梯 `#··/##·/###` → 4，墙 `###/###` → 6，台阶 `###` → 6，竖台阶竖着 `#/#/#` → 6）

**竖台阶放置规则（2.1.0 起）**

- 点方块侧面 → 贴那一侧；点顶/底面 → 朝你面朝的方向
- 点露出的大平面 → 补满另半格，变成整块（掉落 2 个）
- 点垂直侧面 → 在相邻格沿墙接着放
- 潜行点击 → 强制不合并，只往旁边放
- 支持含水；任何水平点击都不会“没反应”（旧版会返回 null，导致放下去顿一下）

**mcworld-audit**

```text
/mcworld audit          # 半径 8（289 个区块）
/mcworld audit 4        # 半径 4（81 个区块）
```

结果写到服务器运行目录的 `mcworld-audit.json`。只带 Windows x64 原生库。

## 已知限制

- 方块 mod 的模型外观没有在客户端里逐一看过，只保证了模型/纹理引用全部解析有效（453 模型 / 171 blockstate）
- 竖台阶的放置逻辑用无头断言验证（18 项，起真服构造 `BlockPlaceContext`），没有真人点击测试
- 竖台阶不是原版形状，和涉及方块形状/连接纹理的 mod 可能有视觉差异
- 木类竖台阶的切石机配方是从木板切的，原版没这种做法
